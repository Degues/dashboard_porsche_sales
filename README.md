# dashboard_porsche_sales
Dashboard de vendas de modelos da Porsche
Desenvolvido para analisar o desempenho de vendas da Porsche, permitindo visualizar indicadores, identificar modelos populares e acompanhar a distribuição geográfica das vendas.

🛠️ Tecnologias utilizadas

HTML
CSS
JavaScript
Excel

🔎 Funcionalidades

Filtros por modelo, Model Year, cidade e método de pagamento.
Indicadores de desempenho (KPIs).
Análise de vendas por modelo e localização.
Identificação dos modelos mais vendidos.
Análise da evolução das vendas por estado.

🎯 Objetivo

Transformar dados comerciais em informações visuais e estratégicas, facilitando a identificação de padrões e apoiando a tomada de decisões.
